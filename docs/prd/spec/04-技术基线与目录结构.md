## 1. 技术基线

**进程模型**：**单仓、两个进程** —— `pnpm dev`（Next.js 前端 + Route Handlers 后端）与 `pnpm worker`（异步任务），缺一不可（安装、启动与 `.env` 实操见 `spec/08-本地开发指南.md` §2–§4）。

| 项 | 选择 |
|---|---|
| 运行时 / 框架 | Node.js ≥ 20.11、TypeScript strict ／ Next.js 15 App Router（Route Handlers 作后端，React 作前端） |
| 数据库 / 校验 | SQLite + `better-sqlite3`（同步 API）、手写 SQL，无 ORM ／ `zod`（请求解析 + 响应断言 + fixture 校验） |
| 图像处理 / 测试 / 样式 | `sharp`（预处理、质量评分、缩略图）／ `vitest` ／ Tailwind CSS |

**不使用**：Prisma / Drizzle（避免 schema 双源）、Redis / BullMQ（SQLite 表即队列）、axios（用内置 `fetch`）。

## 3. 模块边界与依赖方向

```
app/api/**/route.ts        只做：鉴权 → zod 解析 → 调 service → 封装响应
        ▼
domain/*Service            编排与规则；唯一允许跨 repository 的地方；下一层 security/ · auth/ · prompt/ · ark/ · images/
        ▼  只允许向下调用 repository
db/repositories/*  ←→  db/connection ／ storage/local
```

### 3.1 依赖方向铁律

1. **`app/api/**` 不允许直接调用 repository**，必须经过 `domain/*Service`（简单查询除外：`/api/me`、`/api/history`、`/api/config/era-scene`、`/api/health` 可直接调 repository）；
2. **repository 层不允许调用 `ark/`、`images/`、`storage/`**，它只做 SQL；
3. **`prompt/build.ts` 不允许访问数据库**，它接收已查好的 `era` / `scene` / `profile` 对象；
4. **`shared/types.ts` 不允许 import 任何 `server/` 下的东西**（它会被前端打包）；
5. `jobs/handlers/*` 可以调用 `domain/*Service` 与 repository，但不允许调用 `app/api`。

## 4. 跨模块约定

### 4.1 错误处理

`src/server/domain/errors.ts` 定义唯一错误类型（`code` 见 `spec/03-接口契约.md` §5，`message` 是用户可见中文文案，`status` 是 HTTP 状态码）：

```ts
export class AppError extends Error {
  constructor(public code: ErrorCode, message: string, public status: number, public details?: unknown) {
    super(message);
  }
}
```

- Route handler 不得自行组装错误 JSON，**一律 `throw new AppError(...)`**，由 `http/respond.ts` 的 `withErrorHandling()` 包装器转换；
- `withErrorHandling()` 捕获顺序：`AppError` → 按 `status` 返回；`ZodError` → `INVALID_PARAM`；其他 → 记日志并返回 `INTERNAL`（**不把原始 message 透给用户**）；
- worker handler 不得抛 `AppError` 出去，必须捕获并写入任务的 `error_code` / `error_message`。

### 4.2 时间

- 唯一入口 `src/server/domain/time.ts`：`nowIso(): string` 返回 UTC ISO-8601（毫秒精度，`Z` 结尾）；禁止在业务代码里用其他方式生成时间字符串，禁止本地时区格式；"今天"（额度日）用 UTC 日期：`dayKey(): string` → `YYYY-MM-DD`。

### 4.3 数据库

- **进程模型提醒**：`pnpm dev` 与 `pnpm worker` 是**两个进程，共享同一个 SQLite 文件**（§1），两边写入同一个库，因此必须有 busy 处理（见下）。
- `getDb()` 返回单例 `Database`，在**事务之外**执行连接级 PRAGMA：`journal_mode=WAL`、`foreign_keys=OFF`（软删除语义靠应用层，见 `spec/01-领域模型与数据库.md` §2.3）、`synchronous=NORMAL`、`busy_timeout=5000`（`better-sqlite3` 的 `timeout` 选项，等价）。
  **这些 PRAGMA 不得写进 `migrations/*.sql`**：SQLite 禁止在事务内切换 `journal_mode`，而 `migrate.ts` 对每个迁移文件单事务执行，写在迁移里会直接报错或静默失效（`spec/01-领域模型与数据库.md` §5.1）。
- **所有写操作必须包在事务里**（`db.transaction(...)`），跨表写（如"建锚点 + 写审计"）必须在同一事务；涉及"读判 → 写"的排他性事务（如生成入队的非终态检查）一律用 `db.transaction(...).immediate()`（`BEGIN IMMEDIATE`），不用 `.exclusive()`；
- SQLite 返回 `SQLITE_BUSY` / `SQLITE_BUSY_SNAPSHOT` 时按可重试的 `STORAGE_ERROR` 处理（映射见 `spec/03-接口契约.md` §5.1）；
- repository 函数签名遵循：接收**原子值或 DTO**，返回**领域对象**（camelCase），永不返回数据库原始行；所有 JSON 列：写入前 `JSON.stringify`，读取后立即 `JSON.parse` 并在 repository 边界用 zod 校验。

### 4.4 响应

export const ok = <T>(data: T, status = 200) => NextResponse.json(data, { status });
export const withErrorHandling = (handler) => async (req, ctx) => { /* 见 spec/04-技术基线与目录结构.md §4.1 */ };

### 4.5 上传与文件

- 文件系统是唯一存储介质；`storage_key` 由 `storage/index.ts` 的 `buildKey(userId, ext)` 生成：`u{userId}/{uuid}.{ext}`；
- 任何直接拼 `path.join` 的地方都要经过 `LocalStorageProvider`，禁止业务代码散落路径逻辑；
- 写文件用"先写 `.tmp` 再 rename"的原子方式。

### 4.6 异步任务

- 任务来源是**三张表**：`identity_anchors(status='queued')`、`prompt_reverse_jobs(status='queued')` 与 `generations(status='queued')`（`spec/03-接口契约.md` §2 的三类异步操作与之一一对应）；worker 是**单进程、串行为主**（并发度 `WORKER_CONCURRENCY`，默认 1），本期不考虑高并发，正确性优先。注意 worker 与 web 是**两个进程共享同一个 SQLite 文件**（§1、§4.3）；
- 每个 handler 结构固定：`claim → 置 running → 执行 → 写结果 → 置终态`，任何异常都必须落到 `failed`；
- 心跳：每 5 秒 touch `.<DATA_DIR>/worker-heartbeat`（`<DATA_DIR>` = `dirname(DATABASE_PATH)`，默认 `./data`）；
- **启动自检**：`dev` 侧在**启动时**与**每次入队前**读心跳 mtime，超过 15 秒未更新即判定 worker 未存活并**明确报错**——终端打印 `[FATAL] worker 未启动：找不到心跳文件 ./data/worker-heartbeat` 与"异步任务不会被执行"，前端另有"后台还没启动，图片处理会卡住"+ 命令 `pnpm worker`（`ERR-04`）；**禁止把"任务不执行"变成静默行为**（`spec/08-本地开发指南.md` §3.1）。
