## 1. 三个层次

| 层次 | 谁执行 | 在哪 | 覆盖 |
|---|---|---|---|
| **A. 单元测试** | `pnpm test` | `vitest` | 拼装函数、状态机、repository、错误映射、预处理 |
| **B. 契约与链路检查** | `pnpm check:acceptance` | `scripts/acceptance.ts` | 全部 API 端点形状、完整链路、合规拒绝路径 |
| **C. 人工质量验收** | `pnpm check:blind` 产出材料 + 人工 | 评审 | 盲测真实率、年代一致性、AI 感（无法自动化） |

B 必须全绿才能交付。C 本期只交付**材料生成工具与评分表**，不下达最终判定。

- **路径标签**：`[mock]` = `PROVIDER=mock`、离线可复现、无需 `ARK_API_KEY`，`pnpm check:acceptance` 必绿；`[real]` = 需 `ARK_API_KEY` 的手动冒烟，**不纳入自动检查**。
- **唯一自动化判据**：`PROVIDER=mock` 下 `pnpm check:acceptance` 全绿。`PROVIDER=real` 是独立的手动冒烟：**复用 `E2E-01`–`E2E-09` 的同一链路**重跑、人工看图确认，不新增 ID、不算自动检查。

## 3. `pnpm check:acceptance` 的输出格式

```
[DB-01] ✓ 16/16 tables
[SEC-04] ✓ quota rejected, no row created
65 passed, 0 failed, 0 skipped
```

- 计数口径：B 层 65 项（§2.1–§2.8、§2.10）。§2.9 的 `PRE-` / `MARK-` / `PR-10` / `ERA-` 共 22 项是 A 层，由 `pnpm test` 断言，**不进本脚本的计数与末行输出**。
- 任一失败：跳过后续依赖它的检查，打印失败项的**期望值 vs 实际值**，退出码 1；全部通过退出码 0。
- 脚本必须**自带清理**：跑完删除本次创建的 `photos` / `generations` 行与磁盘文件（依据一次运行内记录的 id 列表），不污染本地数据。

## 4. C 层：人工质量验收材料（`pnpm check:blind`）

自动检查无法回答"像不像真实照片"。本期交付**材料生成工具** `pnpm check:blind --out ./blind-runs/<日期>`（生成图样本取自本地 `generation_results` 中 `status='succeeded'` 的行、按 `era_code` 分层各取最多 10 张；真实老照片来源 `docs/老照片/` 与用户自备）：

| 文件 | 内容 |
|---|---|
| `sheet.html` | 盲测页面：每行 2 张图（1 张真实老照片 + 1 张生成图），**随机左右、无标签** |
| `answer-key.json` | 每行的真实标签与左右顺序（评审前不要打开） |
| `score-template.csv` | 列：`行号, 选的哪张是AI, 年代像不像(1-5), 年龄是否偏年轻(是/否), 是否塑料感(是/否), 备注` |
| `report.md` | 空模板，含 `spec/00-总纲.md` §4.4 的六个指标定义与计算方式 |

**注意**：`report.md` 中必须写明"盲测样本集至少 30 组源照片 + 生成结果，评审 ≥ 5 人，且包含逝者家属本人"（来自 `docs/raw/AIGC_PRD.md` §2.4）。

## 5. 每条 ticket 的通用完成判定

在 `tickets/*.md` 的 `## 完成判定` 一节中，除该 ticket 专属项外，下列是**通用要求**：

1. `pnpm check`（类型检查 + lint）零错误，且 `pnpm test` 全绿；
2. 该 ticket 涉及的检查项在 `pnpm check:acceptance` 中通过（A 层 `PRE-` / `MARK-` 项以 `pnpm test` 通过为准）；
3. 新增的环境变量、脚本、目录**已同步更新** `spec/08-本地开发指南.md`；
4. 若改动了 `spec/era-scene-seed.json`，递增了相关 `packVersion` 且 `pnpm seed` 通过；
5. 未引入 `docs/prd/` 未声明的依赖或表结构。

## 6. 明确不在自动检查范围内（诚实边界）

| 项 | 为什么不能自动 | 本期如何兜底 |
