## 4. 实现要点
1. 结果轮询 2s / 180s，终态 `{succeeded, partial, failed}`；超时**不自动停**并保留 `继续看进度`；终态不再轮询（复用 `tickets/T14` 的 `useJobPolling`）。
2. `eraCheck` 三态（年代复核判定 `eraCheckVerdict`）与 `|ageDelta| > 5` 的年龄提示按 `modules/M07-生成后复核与内容审核.md` §5.3 / §5.5；年代复核判定 `eraCheckVerdict` 为 `reject` 的结果图**不隐藏、不阻断下载**；`null` 只显示 `还没检查`，不显示推测性提示。
3. `status === 'queued'` 且 `worker.alive === false` → 立即在进度区上方报错（`后台还没启动，图片处理会卡住` + 一行命令 `pnpm worker`），不得无限转圈，也不得并入 `ErrorNotice`。
4. 两级删除统一走 `ConfirmDialog`，确认与成功提示必须写明「删了拿不回来」；成功提示取 `cascaded.results`；已被 `runPurge()` 抹掉的行返回 `404` 时按「已经删掉了」处理，不报错。
