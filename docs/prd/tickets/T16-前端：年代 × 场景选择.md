## 1. 目标
四个年代卡片、五个场景卡片、组合样片预览、低置信组合的温和提示、张数选择与发起生成可用；**并接住**上传页采纳的反推推荐（`?era=` / `?scene=` 的初值——F4 面板本身已移到 `tickets/T15`，见 `pages/P01-上传与身份确认.md` §4.4）。

## 2. 不做（边界）
- 不新增路由 / 端点 / 响应字段；不在前端拼 prompt，不把反推的 `resultPrompt` 提交回去；不做「是否可生成」的完整判断（服务端是唯一裁判）。
- 不做「自己描述场景」输入框、不提供 prompt 预览；不重复定义视觉 Token、`useJobPolling`、`ErrorNotice`（`tickets/T14`）。

## 4. 实现要点
1. 未提交的选择写 URL（`router.replace`，**不用 `push`**）；`scene` 是 `scenes.id` 整数，**不是** `S1` 这类代号；`count` 缺省不写，服务端默认 2。
2. `SampleSlot` 是样片两态的唯一实现点（年代卡 / 场景卡 / 组合预览三处共用）：无样片时不渲染 `<img>`、不渲染任何占位图，图位写「暂无示例」，`caption` / `visualSignature` 原样展示。
3. 低置信判据用响应里的 `confidenceHintThreshold`，**不写死 `0.6`**；等于阈值时不提示；`profile = null` 时整个组合区不渲染。
4. 采纳反推结果只填 `?era=` 与 `?scene=`，等价于用户手选；`resultPrompt` 仅作展示，不回传、不参与拼装、不用于生图（`spec/05-Prompt工程.md` §11）。
