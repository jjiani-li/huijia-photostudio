## 4. 实现要点
1. `useJobPolling` 六条硬规则：`setTimeout` 递归只排下一次（`enabled` 首帧立即请求一次）、`inFlight` 并发护栏、终止即停、超时停自动但 `refreshNow()` 可续、错误不吞、终态不再轮询；`enabled` 必须每次读最新值（不能首帧闭包钉死）。
2. `ErrorNotice` 主文案**直接用服务端 `error.message`**，前端不重写；未知 `code` 按 `INTERNAL` 渲染；形态与附加动作按 `pages/P00-设计基准与路由.md` §8 的表；worker 未存活提示**不走** `ErrorNotice`。
3. worker 未存活提示只落上传页顶部（文案 + `pnpm worker`）；`SiteHeader` 额度取 `GET /api/me` 的 `quota.remaining` / `quota.limit`，模式小字取 `GET /api/health` 的 `provider.mode`。
4. `public/samples/` **本期为空**：`spec/era-scene-seed.json` 的 `samplePhoto` 全部为 `null`；目录只建不填，前端按"暂无示例"降级为纯文字卡片（`pages/P02-年代与场景选择.md` §4、§5）。将来有真实留存图时按 seed 字段放图，不改代码。
