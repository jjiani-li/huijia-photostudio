## 1. 目标
`scripts/smoke.ts`、`scripts/blind.ts` 就位，`scripts/acceptance.ts` 在 `tickets/T01` 的骨架上补齐 B 层全部用例：`pnpm check:acceptance`（`PROVIDER=mock`）67 项全绿，`pnpm smoke` 走通全链路，`pnpm check:blind` 产出四件人工验收材料。

## 2. 不做（边界）
- 不为任何检查项改期望值 / 删检查项 / `skip`（`spec/09-施工纪律.md` §4 D6）；不新增端点 / 表 / 字段 / 错误码 / 检查项 ID。
- C 层只交付**材料生成工具与评分表**，不下达最终判定；`PROVIDER=real` 不纳入自动检查。

## 4. 实现要点
1. 任一失败：**跳过后续依赖它的检查**，打印失败项的期望值 vs 实际值，退出码 1；全通过退出码 0，末行输出 `67 passed, 0 failed, 0 skipped`。
2. 脚本必须**自带清理**（一次运行内记录的 id 列表驱动），不污染本地数据；所有 fixture 开关必须还原。
3. 前置：`pnpm migrate && pnpm seed` 已跑、`PROVIDER=mock`、worker 已启动——脚本先探测 `GET /api/health`，worker 未存活则**直接失败并提示**。
4. `CMP-02`（`app/` / `components/` / `src/` 字符串字面量与 JSX 的禁用词扫描，含 `修复`）由本脚本执行；`PROVIDER=real` 只走 `pnpm smoke --real` 人工看图。
## 5. 完成判定
```bash
pnpm migrate && pnpm seed && pnpm test && pnpm check
pnpm worker   # 终端 B
PROVIDER=mock pnpm check:acceptance && pnpm smoke
```
- 全部 67 项（含 `CMP-02`）全绿、`pnpm smoke` 走通 `E2E-01` 链路；`pnpm check:blind --out ./blind-runs/<日期>` 产出四件材料且 `report.md` 写明「盲测样本集至少 30 组、评审 ≥ 5 人、含照片中人物的家属本人」；通用项见 `spec/07-验收标准.md` §5。
- 当前实际执行：`pnpm migrate && pnpm seed && pnpm test`（626 用例）`&& pnpm check` 全绿；`pnpm worker` 起在另一终端后 `pnpm check:acceptance` 输出 **67 passed, 0 failed, 0 skipped**、`pnpm smoke` 走通全链路并 `smoke PASS`；`pnpm check:blind --out ./.scratch/blind-run` 产出四件材料（本地无 `succeeded` 生成结果时按空样本集照常产出）。`pnpm check:docs`（17 断言）/ `pnpm test:docs`（50 用例）全绿。
