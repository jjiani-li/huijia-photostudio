- 不写入 `identity_anchors`；不产出任何图片；不绕过 `buildPrompt`；反推结果**不得直接用于生图**；不进历史记录；不占生成额度（不写 `usage_counters.images`）。
- 前端 `ReversePromptPanel` 归 `tickets/T15-前端：上传 → 预处理 → 身份确认.md`（落 `/upload`，照片已存在即可用；依赖边 `T18 → T15`）：面板消费本条的 `POST` / `GET /api/prompt-reverse-jobs`；不新增端点 / 字段 / 环境变量。

## 4. 实现要点
1. 容错解析按 `modules/M03-身份锚点提取.md` §5.5 的同一顺序（`stripFence → JSON.parse → zod → 词表`）；**推荐值越界只置 `null`、不判失败**（推荐是弱约束）；词表命中 → `PROVIDER_ERROR`。
2. 固定 1 张图；messages 组装沿用 `modules/M03-身份锚点提取.md` §5.4（system 用字符串、user 的 text 元素在图片之前）；只取 `choices[0].message.content`，**忽略 `reasoning_content`**。
3. 落库：`succeeded` 时 `result_json` 与 `result_prompt` 非空，`failed` 时 `error_message` 非空；重复反推 = 插新行，不覆盖旧行。
4. `suggest_era_code` 是**代号字符串**（指向 `eras.code`），`suggest_scene_id` 是 **INTEGER**（指向 `scenes.id`）；采纳只填年代与场景，`resultPrompt` 仅展示、不回传、不参与拼装。
