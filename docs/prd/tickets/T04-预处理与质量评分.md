## 1. 目标
`POST /api/photos/:id/preprocess` 把原图整理成「模型读得准」的形态（方向 / 色彩 / 剥离元数据 / 尺寸归一 / jpeg），产出 8 键 `Quality`，落 `photos(kind='preprocessed')`。

## 2. 不做（边界）
- 不修复 / 不美化 / 不超分 / 不锐化 / 不去噪 / 不人脸裁剪（`modules/M02-预处理与质量评分.md` §1.3 禁令清单）。
- 不阻断流程：`usable=false` 仍返回 `200`；不写 `identity_anchors.quality_json`、不写 `content_reviews`；不新增环境变量、不把评分常数做成环境变量。

## 4. 实现要点
1. 流水线顺序不可换：`.rotate()` → `.pipelineColourspace('srgb16').toColourspace('srgb')` → `.resize({..., withoutEnlargement: true})` → `.jpeg({ quality: 92, chromaSubsampling: '4:4:4', mozjpeg: false })`；**禁止** `.withMetadata()` / `.keepMetadata()`。
2. `kind != 'original'` → `INVALID_PARAM`；幂等判重必须在**取到原图行之后、读文件之前**。
3. `Quality` 键名与顺序照抄 `spec/03-接口契约.md` §4，浮点写库前 `Math.round(v * 1000) / 1000`；`usable` / `advice` / `warnings` 按 §6.1、§6.2 的表格逐字实现，文案不得出现「修复」「变清晰」。
