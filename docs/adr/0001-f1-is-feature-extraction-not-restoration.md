# F1 是「关键特征提取与预处理」，不是「老照片修复」

上游需求把 F1 写成"模糊照片修复与增强"（去噪去划痕、分辨率提升、面部细节还原）。我们改写为**关键特征提取与预处理**：把上传的旧照片整理成模型能稳定读取的形态，并从中产出准确的身份锚点。F1 因此不承诺修复效果，不做美颜、不做减龄、不做面部重建，主产物是文本锚点而非图像。

理由：本产品承诺的是"这个人在新场景里仍然是他"，而任何以"修得更好看、更清楚"为目标的处理都会在锚点提取之前把证据替换成 AI 想象出来的一张脸——身份保真从第一步就断了。链路里因此没有任何一步叫"修复"。

## Considered Options

- **保留修复语义，把 F1 做成真正的修复增强。** 放弃：质量提升与身份保真在本产品里方向相反，而且"修复"已被列为禁用措辞（本产品无法兑现这个承诺）。
- **修复与提取并列，先修再提。** 放弃：中间产物是再生图像而非证据，锚点会锚在 AI 画出来的脸上。

## Consequences

- `sharp` 级别的处理只服务于"让视觉模型读得准"，不服务于"让用户看着好看"；预处理图是辅助产物。
- 上游"修复效果"类的验收口径在本项目内不成立，不得据此判定成败；对 F1 的验收只针对锚点的准确性与置信判断。
- 后续若有人提议"顺手把照片修清楚一点"，这是已被否决的方向，不是遗漏。
