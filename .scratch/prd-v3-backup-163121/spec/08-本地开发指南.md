# 08 · 本地开发指南

> **层级**：规范层 · 全局约束（不可违背）
> **上游**：`spec/04-技术基线与目录结构.md`、`spec/03-接口契约.md` ／ `docs/火山引擎接口文档.md`
> **下游**：`modules/M01`–`M08`、`pages/P00`–`P01`、`tickets/*`

> 目标：**一条命令起前后端，零外部依赖跑通全链路**。真实 Ark 调用是可切换的增强路径，不是前置条件。

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| Node.js | ≥ 20.11（`better-sqlite3` 与 Next.js 15 需要） |
| 包管理器 | pnpm ≥ 9 |
| 操作系统 | Windows / macOS / Linux（开发主力为 Windows） |
| 外部服务 | **无**。SQLite 是文件库，存储是本地目录，Ark 与短信都有 mock 实现 |

---

## 2. 一次性初始化

```bash
pnpm install
cp .env.example .env      # Windows: copy .env.example .env
pnpm migrate              # 建库 + 建表（执行 migrations/*.sql）
pnpm seed                 # 写入 4 个年代 / 5 个场景 / 20 组组合档案
```

`pnpm seed` 结束时会打印并断言 `eras=4, scenes=5, era_scene_profiles=20`，不符则非零退出。

---

## 3. 日常开发

```bash
pnpm dev        # 前端 + 后端（Next.js dev server，默认 http://localhost:3000）
pnpm worker     # 异步任务 worker（另一个终端，必须开）
pnpm test       # 单元测试
pnpm check      # 类型检查 + lint
```

**必须同时运行 `pnpm dev` 与 `pnpm worker`**：锚点提取与生图都是异步任务，没有 worker 会一直停在 `queued`。前端在 `GET /api/health` 检测到 worker 未存活时会显示提示（见 `spec/03-接口契约.md` §2.3）。

---

## 4. 环境变量（`.env`）

| 变量 | 默认 | 说明 |
|---|---|---|
| `DATABASE_PATH` | `./data/app.db` | SQLite 文件路径 |
| `STORAGE_DIR` | `./storage` | 照片文件根目录 |
| `PROVIDER` | `mock` | Ark 调用模式：`mock`（fixture 回放）/ `real`（真实调用） |
| `ARK_API_KEY` | 空 | 仅在 `PROVIDER=real` 时必填。**绝不写入仓库** |
| `ARK_BASE_URL` | `https://ark.cn-beijing.volces.com/api/v3` | 数据面 base |
| `ARK_VISION_MODEL` | `doubao-seed-2-1-turbo-260628` | 多模态/生文模型（读图、复核、审核） |
| `ARK_IMAGE_MODEL` | `doubao-seedream-5-0-lite-260128` | 生图模型 |
| `ARK_TIMEOUT_SECONDS` | `120` | 单次上游调用超时 |
| `SMS_PROVIDER` | `console` | `console`（验证码打到终端）/ `real`（本期不实现） |
| `DEV_LOGIN_CODE` | `000000` | `SMS_PROVIDER=console` 时的万能验证码 |
| `MAX_UPLOAD_MB` | `20` | 单张上传上限 |
| `WORKER_STALE_MINUTES` | `10` | 任务回收阈值（见 `spec/03-接口契约.md` §2.2） |
| `WORKER_CONCURRENCY` | `1` | worker 同时处理的任务数。本期正确性优先，保持 1 |
| `JOB_TIMEOUT_SECONDS` | `120` | 单个任务执行超时 |
| `GENERATION_DEFAULT_COUNT` | `2` | 前端默认生成张数（允许 2–4） |
| `WATERMARK_DEFAULT` | `false` | 传给 Seedream 的 `watermark`；默认关闭以保真实感 |
| `AIGC_IMPLICIT_MARKER` | `true` | 是否在生成文件写入隐式标识元数据（见 `spec/06-合规与风控.md`） |

`.env`、`./data/`、`./storage/` 必须在 `.gitignore` 中。

## 5. 本地替身（mock）策略

本项目的三个外部依赖都有本地实现，**默认全部走本地实现**：

| 依赖 | 抽象 | 本地实现 | 真实实现 | 切换 |
|---|---|---|---|---|
| Ark 模型（读图/生文/生图） | `ArkProvider` | `MockArkProvider`：回放 `fixtures/ark/*.json` + `fixtures/images/*` | `RealArkProvider`：直连 `chat/completions` 与 `images/generations` | `PROVIDER` |
| 短信验证码 | `SmsSender` | `ConsoleSmsSender`：打到终端，且在响应里返回 `devCode` | （本期不实现） | `SMS_PROVIDER` |
| 图片存储 | `StorageProvider` | `LocalStorageProvider`：`./storage/` | （本期不实现） | 无开关，仅一个实现 |

### 5.1 Fixtures 目录

```
fixtures/
├── ark/
│   ├── anchor-extract.json       ← 锚点提取的响应（形状同 /api/anchors/:id 的 anchor）
│   ├── anchor-extract-fail.json  ← 触发 ANCHOR_LOW_QUALITY 的样本
│   ├── image-generation.json     ← 生图响应（url 指向 fixtures/images/）
│   ├── era-check.json            ← 穿帮复核结果（含一个穿帮样本）
│   └── safety-review.json        ← 内容审核结果
└── images/
    ├── generated-01.png          ← 从 docs/output/ 复制
    ├── generated-02.png
    └── generated-03.png
```

`MockArkProvider` 的行为规则：

- 读图类调用：返回 `anchor-extract.json`，但把 `features.ageRange` 与 `anchorText` 中的年龄替换为**可从文件名推断的稳定伪随机值**（同一输入文件永远得到同一输出，保证测试可重复）；
- 生图类调用：按 `(anchorId + eraCode + sceneId + ordinal)` 的哈希在 `fixtures/images/` 中**确定性选图**，写入本地存储后返回本地 URL；
- 每次调用固定 `sleep 300–800ms`，模拟异步感，避免前端轮询逻辑在 mock 下从未被真正测过；
- 传入 `fixtures` 中不存在的场景时抛 `PROVIDER_ERROR`，便于测试失败路径。

### 5.2 切换到真实调用

```bash
# .env
PROVIDER=real
ARK_API_KEY=<你的 key>

pnpm dev
pnpm worker
```

真实调用走**直连 HTTP + 模型名**（`docs/火山引擎接口文档.md` §2.3 / §1 已验证可用）。**不要**改造成 arkcli 或 `ep-...` Endpoint 方式——那条路只在 arkcli 的 platform profile 下必需，直连 HTTP 不需要。

`GET /api/health` 的 `provider.mode` 会反映当前模式，前端在标题栏以一行小字显示（便于避免误用真实额度）。

## 6. 数据库操作

```bash
pnpm migrate          # 应用 migrations/ 下未应用的迁移
pnpm seed             # 幂等 upsert 配置资产
pnpm db:reset         # 删除 data/app.db 与 storage/，重建并 seed（破坏性，仅本地）
```

手工查看：

```bash
node -e "const db=require('better-sqlite3')(process.env.DATABASE_PATH||'./data/app.db');console.log(db.prepare('select code,name from eras').all())"
```

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 任务一直停在 `queued` | worker 没启动 | 另开终端跑 `pnpm worker` |
| `pnpm seed` 退出码非零 | 种子文件被改动导致数量不为 4/5/20 | 检查 `spec/era-scene-seed.json` |
| `GET /api/health` 的 `ok=false` | 未执行 migrate/seed | `pnpm migrate && pnpm seed` |
| 上传 heic 报 `INVALID_FILE_TYPE` | `sharp` 未编译 heif 支持 | 本地先用 jpg 验证；heic 支持列为已知限制 |
| `better-sqlite3` 安装失败 | 无当前 Node 版本的预编译产物 | 升级 Node 到 LTS，或本地有 C++ 工具链时从源码编译 |
| 生图报 `InvalidParameter`（size） | `eras.default_size` 低于 3,686,400 像素 | 改回 `2048x2048` |
| 真实模式下图片 URL 下载 403 | 签名 URL 过期（86400s） | 这是 worker 转存失败导致；检查 worker 日志 |
| 生成结果全是同一张图 | mock provider 选图哈希实现有误 | 见 `spec/08-本地开发指南.md` §5.1 确定性选图规则 |
