# 14 · 接口契约

> **前后端之间唯一的约定。** 前端与后端可以并行开发，前提是本文件被冻结。
>
> 后端实现：Next.js App Router Route Handlers，代码位于 `app/api/**/route.ts`。
> 前端只通过本文件列出的端点取数据，**不得直接读数据库**。

---

## 1. 通用约定

### 1.1 传输

| 项 | 约定 |
|---|---|
| Base | 同源 `/api`，无跨域配置 |
| 编码 | 请求与响应均为 `application/json; charset=utf-8`（上传与取图为例外） |
| 字段命名 | **`camelCase`**。数据库的 `snake_case` 只在 repository 层出现，不得泄漏到 API |
| 时间 | ISO-8601 UTC 字符串，如 `2026-09-17T15:07:42.000Z` |
| 未知字段 | 服务端忽略；前端必须容忍响应中出现未声明字段 |

### 1.2 鉴权

- 登录成功后服务端下发 cookie：`sid=<base64url(32B)>`，属性 `HttpOnly; SameSite=Lax; Path=/; Max-Age=2592000`。
- 服务端只存 `sha256(token)`，明文不落库（`sessions.token_hash`）。
- 所有受保护端点在 handler 开头调用 `requireUser()`；失败返回 `401 UNAUTHENTICATED`。
- 受保护端点清单：除 `POST /api/auth/code`、`POST /api/auth/login`、`GET /api/health` 外的**全部**端点。
- 登出：`POST /api/auth/logout` 写 `sessions.revoked_at` 并清 cookie。

### 1.3 错误响应（统一 envelope）

```json
{
  "error": {
    "code": "QUOTA_EXCEEDED",
    "message": "今天的生成额度用完了，明天再来吧",
    "details": {}
  }
}
```

- HTTP 状态码语义与 `code` 对应（见 §5 表）；
- `message` 是**可直接展示给用户的中文文案**，语气遵循 `00-总纲.md` 与 `15-前端-设计基准与路由.md` §5（第二人称、平实、不煽情）；
- `details` 可选，仅用于开发调试，前端不应依赖其结构（例外：`INVALID_PARAM` 的 `details.fields` 与 `ANCHOR_LOW_QUALITY` 的 `details.quality`）。

### 1.4 成功响应

**不使用 envelope**。直接返回业务对象，例如 `{ "photo": {...} }` 或 `{ "items": [...] }`。
列表端点统一使用 `{ items, nextCursor }` 形状。

### 1.5 幂等与并发

| 端点 | 语义 |
|---|---|
| `POST /api/auth/code` | 非幂等；同 `identifier` 60 秒节流 |
| `POST /api/photos` | 非幂等；同用户同内容 `sha256` 复用已存在行（不重复落盘） |
| `POST /api/anchors` | **非幂等**：每次调用创建新行。前端必须在请求期间禁用按钮 |
| `POST /api/anchors/:id/retry` | **非幂等**：创建新行，`attempt = 旧 + 1` |
| `POST /api/generations` | 非幂等。同一用户同时只允许 1 个非终态生成任务，否则 `409 GENERATION_IN_PROGRESS` |
| `POST /api/generations/:id/retry` | 非幂等：创建新行并继承全部设定 |
| `DELETE *` | **幂等**：重复删除返回 200 |

## 2. 异步任务与轮询协议

链路中有两个异步操作：**锚点提取**（③）与**生成**（⑦）。二者共用同一套协议。

```
status: queued ──▶ running ──▶ succeeded | failed | partial(仅生成)
```

### 2.1 轮询规则（前端）

| 任务 | 端点 | 间隔 | 超时 | 终止条件 |
|---|---|---|---|---|
| 锚点提取 | `GET /api/anchors/:id` | 1.5s | 90s | `status ∈ {succeeded, failed}` |
| 生成 | `GET /api/generations/:id` | 2s | 180s | `status ∈ {succeeded, partial, failed}` |

- 超时后前端展示"还在处理，可以先去别处看看"，**继续保留轮询按钮**（不自动停）。
- 前端不得用 `setInterval` 叠加请求；必须等上一次响应回来再排下一次。

### 2.2 超时与回收（后端）

- worker 启动时执行一次回收：把 `status='running'` 且 `started_at` 早于 `WORKER_STALE_MINUTES`（默认 10 分钟）的任务回退为 `queued`，`attempt` 不变。
- 任务在 `running` 期间超过 `JOB_TIMEOUT_SECONDS`（默认 120s）视为失败。
- **自动重试**：仅对瞬时错误（`PROVIDER_TIMEOUT`、`PROVIDER_ERROR`、`STORAGE_ERROR`）自动重试 1 次；`attempt ≥ 1` 后不再自动重试。
- 用户侧"再来一组"/"重新提取"永远走**新建行**，不覆盖历史。

### 2.3 worker 存活探测

worker 每 5 秒写一次心跳文件 `.<DATA_DIR>/worker-heartbeat`（内容为当前 ISO 时间）。`GET /api/health` 读取该文件的 mtime，超过 15 秒未更新则 `worker.alive=false`。

前端在 `worker.alive === false` 时于上传页顶部显示一条温和提示："后台还没启动，图片处理会卡住"，并给出命令 `pnpm worker`。

## 3. 端点详表

### 3.1 账号与会话

#### `POST /api/auth/code`

请求：
```json
{ "identifier": "13800138000", "channel": "phone" }
```
`channel` 可选：`phone` | `email`；缺省时按 `identifier` 是否含 `@` 自动判定。

响应 `200`：
```json
{ "sent": true, "expiresInSec": 600, "devCode": "000000" }
```
- `devCode` **仅在 `SMS_PROVIDER=console` 时出现**，生产实现必须不返回该字段。
- 节流：同 `identifier` 60 秒内已有未消费记录 → `429 CODE_RATE_LIMITED`。

#### `POST /api/auth/login`

请求：`{ "identifier": "13800138000", "code": "000000" }`

响应 `200`：`{ "user": { ...User } }` + `Set-Cookie: sid=...`

规则：码不存在或已用 → `400 CODE_INVALID`；已过期 → `400 CODE_EXPIRED`；成功则写 `consumed_at`、`users.last_login_at`，首次登录自动建用户（`nickname` 默认 `用户{id 后 4 位}`）。

#### `POST /api/auth/logout`

响应 `200`：`{ "ok": true }`

#### `GET /api/me`

响应 `200`：
```json
{
  "user": { "id": 1, "phone": "138****8000", "email": null, "nickname": "用户0001", "status": 1, "createdAt": "..." },
  "quota": { "day": "2026-09-17", "images": 6, "limit": 20, "remaining": 14 }
}
```
手机号/邮箱在响应中**必须脱敏**。

### 3.2 照片资产

#### `POST /api/photos`

`multipart/form-data`，字段名 `file`。接受 `image/jpeg`、`image/png`、`image/webp`、`image/heic`；单文件 ≤ `MAX_UPLOAD_MB`（默认 20）。

响应 `201`：
```json
{ "photo": {
  "id": 12, "kind": "original", "url": "/api/photos/12/file",
  "mime": "image/jpeg", "bytes": 672370, "width": 1600, "height": 1200,
  "sha256": "…", "createdAt": "…"
} }
```

规则：写入 `storage/u<userId>/<uuid>.<ext>`；同用户内 `sha256` 命中未删除行则直接返回已有行（不重复落盘）；同一次请求同时写一条 `content_reviews(stage='upload')`（见 `10-后端-生成后复核与内容审核.md`）。

#### `POST /api/photos/:id/preprocess`

同步执行（`sharp`，预期 < 2s）。响应 `200`：
```json
{
  "photo": { "id": 13, "kind": "preprocessed", "url": "/api/photos/13/file", "width": 2048, "height": 1536, ... },
  "quality": {
    "usable": true,
    "faceDetected": true,
    "faceCount": 1,
    "sharpness": 0.62,
    "readability": 0.78,
    "damageLevel": 0.21,
    "warnings": ["原图分辨率偏低，面部细节可能不足"],
    "advice": null
  }
}
```

规则：**不修复、不美化**，只做方向校正、色彩空间统一、尺寸归一（长边 ≥ 1600px，不足则不做放大）、EXIF 剥离。若 `usable = false` 仍返回 `200`，由前端决定是否放行（见 `05-后端-预处理与质量评分.md`）。

重复调用：同一 `sourcePhotoId` 已存在 `preprocessed` 行则**直接返回该行**（幂等）。

#### `GET /api/photos/:id/file`

查询参数：`w`（可选，整数，目标宽度；服务端按比例缩放并转 jpeg）。不带 `w` 时返回原文件。

响应：二进制，`Content-Type` 取 `photos.mime`（`w` 生效时为 `image/jpeg`）。
响应头：`Cache-Control: private, max-age=3600`；当 `kind='generated'` 额外带 `X-AIGC-Generated: true`。

规则：必须校验照片属于当前用户且未软删除，否则 `404 NOT_FOUND`（不返回 403，避免探测）。

#### `DELETE /api/photos/:id`

响应 `200`：`{ "ok": true, "cascaded": { "preprocessed": 1, "anchors": 1, "generations": 2, "results": 5 } }`

规则：软删除（`deleted_at`），级联标记所有派生行（见 `11-后端-账号历史与彻底删除.md`）。物理文件由清理任务延迟删除。

### 3.3 身份锚点（F1）

#### `POST /api/anchors`

请求：
```json
{ "photoIds": [12, 15], "preprocessedPhotoId": 13 }
```

响应 `202`：`{ "anchor": { ...Anchor } }`（`status: "queued"`）

校验顺序（任一失败即返回对应错误）：

| 条件 | 错误 |
|---|---|
| `photoIds` 为空或 > 5 张 | `400 INVALID_PARAM` |
| 任一 photo 不属于当前用户或已删除 | `404 NOT_FOUND` |
| `preprocessedPhotoId` 缺省 | 服务端自动对 `photoIds[0]` 执行预处理并落库 |
| 提交的照片 `kind='generated'` | `400 INVALID_PARAM`（防链式自举） |

副作用：写 `audit_logs(action='anchor.extract')`；创建非终态 `identity_anchors` 行。

#### `GET /api/anchors/:id`

响应 `200`：
```json
{ "anchor": {
  "id": 3, "status": "succeeded", "attempt": 0,
  "anchorText": "75-85岁老年男性，留灰白短寸发型…",
  "features": { "gender": "男", "ageRange": "75-85岁", "hair": "…", "faceShape": "…",
                "forehead": "…", "eyebrows": "…", "eyes": "…", "nose": "…",
                "mouth": "…", "skin": "…", "distinctive": "…", "build": "…" },
  "model": "doubao-seed-2-1-turbo-260628",
  "promptVersion": "anchor-v1",
  "quality": { ...同 preprocess 的 quality },
  "confirmedByUser": false, "confirmedAt": null,
  "error": null,
  "sourcePhotos": [ { "id": 12, "url": "/api/photos/12/file" } ],
  "preprocessedPhoto": { "id": 13, "url": "/api/photos/13/file" },
  "createdAt": "…", "finishedAt": "…"
} }
```

`status='failed'` 时：`error = { "code": "PROVIDER_TIMEOUT", "message": "…" }`。

#### `POST /api/anchors/:id/confirm`

请求：
```json
{ "confirmed": true, "consents": ["photo_usage", "family_agreement"] }
```

响应 `200`：`{ "anchor": { ...Anchor, "confirmedByUser": true, "confirmedAt": "…" }, "consents": ["photo_usage","family_agreement"] }`

规则：
- 仅 `status='succeeded'` 可确认，否则 `409 ANCHOR_NOT_CONFIRMED`（复用同一码，语义为"锚点不可用"）；
- `consents` **必须同时包含两项**，缺任意一项 → `400 INVALID_PARAM`；
- 服务端写 `consents` 两行（幂等：同 `anchorId` + `scope` 未吊销则复用）与 `audit_logs(action='anchor.confirm' / 'consent.agree')`。

#### `POST /api/anchors/:id/retry`

响应 `202`：`{ "anchor": { ...Anchor } }`（**新行**，`attempt = 旧 + 1`，`inputPhotoIds` / `preprocessedPhotoId` 继承）

#### `DELETE /api/anchors/:id`

响应 `200`：`{ "ok": true, "cascaded": { "generations": 2, "results": 5 } }`

响应 `200`：
```json
{
  "version": "seed-v1",
  "confidenceHintThreshold": 0.6,
  "realismAnchor": "真实照片，随手拍的生活照，…",

      "caption": "黑白照，稍微泛黄，像老一辈压在箱底的那张相片",
      "sampleUrl": "/api/photos/31/file?w=600", "sortOrder": 1 }
  ],
  "scenes": [
    { "id": 3, "code": "S3", "name": "城市公园", "slug": "city-park", "category": "outdoor",
      "caption": "公园里边，草坪树荫，长椅步道",

  ],
```

规则：

- 该端点**不需要登录**也可访问？——**需要登录**。前端在登录后于年代选择页加载一次并缓存。

### 3.5 生成（F2）

#### `POST /api/generations`

请求：
```json
{ "anchorId": 3, "eraCode": "E4", "sceneId": 3, "count": 2 }
```
`count` 可为 2 / 3 / 4（缺省 2）。

响应 `202`：`{ "generation": { ...Generation } }`

校验顺序：

| 条件 | 错误 |
|---|---|
| `count` 不在 {2,3,4} | `400 INVALID_PARAM` |
| `eraCode` / `sceneId` 不存在或 `is_active=0` | `400 INVALID_PARAM` |
| 锚点不属于当前用户 | `404 ANCHOR_NOT_FOUND` |
| 锚点 `status != 'succeeded'` 或 `confirmed_by_user != 1` | `409 ANCHOR_NOT_CONFIRMED` |
| `consents` 中 `photo_usage` 不存在或已吊销 | `403 CONSENT_REQUIRED` |
| 今日 `usage_counters.images + count > users.daily_image_quota` | `429 QUOTA_EXCEEDED` |
| 该用户已有非终态 `generations` | `409 GENERATION_IN_PROGRESS` |

副作用：拼装 prompt 并**全文落库**；`reference_photo_ids = [preprocessedPhotoId]`；`params_json` 记录 `size`（取 `eras.default_size`）、`outputFormat`、`watermark`、`provider`；`usage_counters` 预扣 `count` 张（失败时在 worker 里回滚未产出的张数）。

#### `GET /api/generations/:id`

响应 `200`：
```json
{ "generation": {
  "id": 7, "status": "succeeded",
  "eraCode": "E4", "eraName": "2010-2020年代",
  "sceneId": 3, "sceneName": "城市公园",
  "requestedCount": 2, "attempt": 0,
  "prompt": "【身份锚点】…", "templateVersion": "tpl-v1",
  "params": { "size": "2048x2048", "outputFormat": "png", "watermark": false, "provider": "mock" },
  "error": null,
  "createdAt": "…", "finishedAt": "…",
  "results": [
    { "id": 21, "photoId": 41, "url": "/api/photos/41/file", "width": 2048, "height": 2048,
      "seed": 123456,
      "eraCheck": { "passed": true, "verdict": "pass", "findings": [], "model": "…" },
      "ageDelta": -2, "realismScore": null, "userFeedback": null }
  ]
} }
```

规则：`status` 非终态时 `results` 为已有部分（可能为空数组）；`prompt` 在**所有状态**都返回（本期无隐藏需求，且便于调试）。

#### `POST /api/generations/:id/retry`

响应 `202`：`{ "generation": { ...Generation } }`（**新行**，继承 `anchorId` / `eraCode` / `sceneId` / `count` / `params`，`attempt = 0`）

允许的原任务状态：`succeeded` / `partial` / `failed`；非终态 → `409 GENERATION_IN_PROGRESS`。
额度不足 → `429 QUOTA_EXCEEDED`。

#### `POST /api/results/:id/feedback`

请求：`{ "feedback": 1 }`（`1` 喜欢 / `-1` 不喜欢 / `null` 取消）

响应 `200`：`{ "result": { ...GenerationResult } }`

### 3.6 历史

#### `GET /api/history?cursor=<opaque>&limit=20`

响应 `200`：
```json
{ "items": [
  { "anchorId": 3, "anchorText": "75-85岁老年男性…", "confirmedAt": "…",
    "sourcePhoto": { "id": 12, "url": "/api/photos/12/file?w=400" },
    "preprocessedPhoto": { "id": 13, "url": "/api/photos/13/file?w=400" },
    "generations": [
      { "id": 7, "eraCode": "E4", "eraName": "2010-2020年代",
        "sceneId": 3, "sceneName": "城市公园", "status": "succeeded", "createdAt": "…",
        "results": [ { "id": 21, "photoId": 41, "url": "/api/photos/41/file?w=400", "userFeedback": null } ] }
    ] }
], "nextCursor": null }
```

规则：
- 排序：按 `identity_anchors.created_at DESC`；
- `cursor` 是不透明字符串（实现为 base64(createdAt|id)），前端只回传，不解析；
- 只返回**未软删除**的照片；
- `generations` 最多返回该锚点下最近 10 条。

## 4. TypeScript 形状（前后端共享）

> 放在 `src/shared/types.ts`，**前后端唯一共用文件**。字段名与 §3 严格一致。

```ts
export type Iso = string;

export interface User { id: number; phone: string | null; email: string | null; nickname: string; status: number; createdAt: Iso; }

export interface Quota { day: string; images: number; limit: number; remaining: number; }

export interface Photo { id: number; kind: 'original' | 'preprocessed' | 'generated';
  url: string; mime: string; bytes: number; width: number | null; height: number | null; sha256: string; createdAt: Iso; }

export interface Quality { usable: boolean; faceDetected: boolean; faceCount: number;
  sharpness: number; readability: number; damageLevel: number; warnings: string[]; advice: string | null; }

export interface AnchorFeatures { gender: string; ageRange: string; hair: string; faceShape: string;
  forehead: string; eyebrows: string; eyes: string; nose: string; mouth: string; skin: string;
  distinctive: string; build: string; }

export interface Anchor { id: number; status: 'queued' | 'running' | 'succeeded' | 'failed';
  attempt: number; anchorText: string | null; features: AnchorFeatures | null;
  model: string; promptVersion: string; quality: Quality | null;
  confirmedByUser: boolean; confirmedAt: Iso | null;
  error: { code: string; message: string } | null;
  sourcePhotos: Photo[]; preprocessedPhoto: Photo | null; createdAt: Iso; finishedAt: Iso | null; }

export interface EraOption { code: string; name: string; slug: string; isMono: boolean;
  caption: string; sampleUrl: string | null; sortOrder: number; }

export interface SceneOption { id: number; code: string; name: string; slug: string;
  category: string | null; caption: string; coverUrl: string | null; sortOrder: number; }

export interface EraSceneProfile { eraCode: string; sceneId: number; confidence: number; visualSignature: string; }

export interface EraSceneConfig { version: string; confidenceHintThreshold: number; realismAnchor: string;
  eras: EraOption[]; scenes: SceneOption[]; profiles: EraSceneProfile[]; }

export interface EraCheck { passed: boolean; verdict: 'pass' | 'review' | 'reject';
  findings: Array<{ item: string; reason: string }>; model: string | null; }

export interface GenerationResult { id: number; photoId: number; url: string;
  width: number | null; height: number | null; seed: number | null;
  eraCheck: EraCheck | null; ageDelta: number | null; realismScore: number | null; userFeedback: 1 | -1 | null; }

export interface Generation { id: number; status: 'queued' | 'running' | 'succeeded' | 'partial' | 'failed';
  eraCode: string; eraName: string; sceneId: number; sceneName: string;
  requestedCount: number; attempt: number; prompt: string; templateVersion: string;
  params: { size: string; outputFormat: 'png' | 'jpeg'; watermark: boolean; provider: 'mock' | 'real' };
  error: { code: string; message: string } | null;
  createdAt: Iso; finishedAt: Iso | null; results: GenerationResult[]; }

export interface HistoryItem { anchorId: number; anchorText: string; confirmedAt: Iso | null;
  sourcePhoto: Photo; preprocessedPhoto: Photo | null; generations: Generation[]; }

export interface ApiError { error: { code: ErrorCode; message: string; details?: unknown } }
```

## 5. 错误码总表

| code | HTTP | 触发场景 | 用户可见文案（示例） |
|---|---|---|---|
| `UNAUTHENTICATED` | 401 | 未登录或会话过期 | 请先登录 |
| `FORBIDDEN` | 403 | 访问他人资源 | 没有权限访问这张照片 |
| `NOT_FOUND` | 404 | 资源不存在或已删除 | 这张照片找不到了 |
| `INVALID_PARAM` | 400 | 参数校验失败（含 `details.fields`） | 选择有误，请重新选一下 |
| `INVALID_FILE_TYPE` | 400 | 非 jpg/png/webp/heic | 暂时只支持 jpg、png、webp、heic |
| `FILE_TOO_LARGE` | 413 | 超过 `MAX_UPLOAD_MB` | 这张照片太大了，换一张小一点的 |
| `CODE_INVALID` | 400 | 验证码错误或已使用 | 验证码不对，再试一次 |
| `CODE_EXPIRED` | 400 | 验证码超时 | 验证码过期了，重新获取一个 |
| `CODE_RATE_LIMITED` | 429 | 60 秒内重复发码 | 刚刚已经发过了，稍等一下 |
| `CONSENT_REQUIRED` | 403 | 未勾选授权确认 | 需要先确认照片使用授权 |
| `ANCHOR_NOT_FOUND` | 404 | 锚点不存在 | 这次的人物特征记录找不到了 |
| `ANCHOR_NOT_CONFIRMED` | 409 | 锚点未成功或未确认 | 需要先确认"这就是他"，才能开始生成 |
| `ANCHOR_LOW_QUALITY` | 422 | 提取质量过低（`details.quality`） | 这张照片的人物特征看不清，建议换一张更清楚的 |
| `GENERATION_IN_PROGRESS` | 409 | 已有非终态生成任务 | 上一组还在生成，稍等一下 |
| `QUOTA_EXCEEDED` | 429 | 超过每日额度 | 今天的生成额度用完了，明天再来吧 |
| `CONTENT_REJECTED` | 422 | 内容审核拒绝 | 这张照片暂时无法处理 |
| `PROVIDER_ERROR` | 502 | 上游模型返回错误 | 生成服务暂时不可用，请稍后重试 |
| `PROVIDER_TIMEOUT` | 504 | 上游超时 | 生成花的时间有点长，请重试一次 |
| `STORAGE_ERROR` | 500 | 磁盘读写失败 | 保存失败，请重试 |
| `INTERNAL` | 500 | 兜底 | 出了点小问题，请重试 |

### 5.1 上游错误码 → 本项目错误码的映射

见 `09-后端-生成编排.md` §5（`05-后端-...` → worker 层统一映射）。摘要：

| 上游 | 映射 |
|---|---|
| `InvalidParameter`（size 不合法） | `INTERNAL`（属于我方拼装 bug，不打给用户） |
| `ModelNotOpen` | `PROVIDER_ERROR` |
| `InvalidEndpointOrModel.NotFound` | `PROVIDER_ERROR` |
| HTTP 429 / 限流 | `PROVIDER_ERROR`（可重试） |
| 网络超时 / fetch abort | `PROVIDER_TIMEOUT`（可重试） |
| `InternalServiceError` | `PROVIDER_ERROR`（可重试） |
| 图片下载失败（签名 URL 过期） | `STORAGE_ERROR`（可重试） |

## 6. 前端调用禁忌

1. **不要**在前端拼 prompt，也不要把 prompt 回传给服务端；
2. **不要**在前端做"是否可生成"的全部判断——服务端是唯一裁判，前端只做体验优化（按钮置灰）；
3. **不要**直接构造图片 URL 路径，一律使用响应中的 `url` 字段；
4. **不要**解析 `cursor`；
5. **不要**轮询 `succeeded`/`failed` 之后的任务（浪费额度与日志）。
