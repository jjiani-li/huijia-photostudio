# 17 · 验收标准与自动化检查

> 每条 ticket 的"完成"判定都指向本文件的检查项 ID。**检查跑不绿 = ticket 未完成。**

---

## 1. 三个层次

| 层次 | 谁执行 | 在哪 | 覆盖 |
|---|---|---|---|
| **A. 单元测试** | `pnpm test` | `vitest` | 拼装函数、状态机、repository、错误映射 |
| **B. 契约与链路检查** | `pnpm check:acceptance` | `scripts/acceptance.ts` | 全部 API 端点形状、完整链路、合规拒绝路径 |
| **C. 人工质量验收** | `pnpm check:blind` 产出材料 + 人工 | 评审 | 盲测真实率、年代一致性、AI 感（无法自动化） |

B 必须全绿才能交付。C 本期只交付**材料生成工具与评分表**，不下达最终判定。

---

## 2. B 层检查项（`pnpm check:acceptance`）

命令执行前置条件：`pnpm migrate && pnpm seed` 已跑；`PROVIDER=mock`；worker 已启动（脚本会先探测 `/api/health`，worker 未存活则直接失败并提示）。

## 3. `pnpm check:acceptance` 的输出格式

```
[DB-01] ✓ 15/15 tables
[DB-02] ✓ eras=4 scenes=5 profiles=20
...
[E2E-01] ✓ 14 steps in 8.3s
[SEC-04] ✓ quota rejected, no row created
...
──────────────────────────────────
42 passed, 0 failed, 0 skipped
```

- 任一失败：跳过后续依赖它的检查，打印失败项的**期望值 vs 实际值**，退出码 1；
- 全部通过：退出码 0；
- 脚本必须**自带清理**：跑完删除本次创建的 `photos` / `generations` 行与磁盘文件（依据一次运行内记录的 id 列表），不污染本地数据。

## 4. C 层：人工质量验收材料（`pnpm check:blind`）

自动检查无法回答"像不像真实照片"。本期交付**材料生成工具**：

```bash
pnpm check:blind --out ./blind-runs/2026-09-17
```

输出：

| 文件 | 内容 |
|---|---|
| `sheet.html` | 盲测页面：每行 2 张图（1 张真实老照片 + 1 张生成图），**随机左右、无标签** |
| `answer-key.json` | 每行的真实标签与左右顺序（评审前不要打开） |
| `score-template.csv` | 列：`行号, 选的哪张是AI, 年代像不像(1-5), 年龄是否偏年轻(是/否), 是否塑料感(是/否), 备注` |
| `report.md` | 空模板，含 `00-总纲.md` §4.4 的六个指标定义与计算方式 |

生成图样本来源：本地 `generation_results` 中所有 `status='succeeded'` 的结果，按 `era_code` 分层各取最多 10 张。真实老照片来源：`docs/老照片/` 与用户自备。

**注意**：`report.md` 中必须写明"盲测样本集至少 30 组源照片 + 生成结果，评审 ≥ 5 人，且包含逝者家属本人"（来自 `docs/raw/AIGC_PRD.md` §2.4）。

## 5. 每条 ticket 的通用完成判定

在 `tickets/*.md` 的 `## 完成判定` 一节中，除该 ticket 专属项外，下列是**通用要求**：

1. `pnpm check`（类型检查 + lint）零错误；
2. `pnpm test` 全绿；
3. 该 ticket 涉及的检查项在 `pnpm check:acceptance` 中通过；
4. 新增的环境变量、脚本、目录**已同步更新** `18-本地开发指南.md`；
5. 若改动了 `13-era-scene-seed.json`，递增了相关 `packVersion` 且 `pnpm seed` 通过；
6. 未引入 `docs/prd/` 未声明的依赖或表结构。

## 6. 明确不在自动检查范围内（诚实边界）

| 项 | 为什么不能自动 | 本期如何兜底 |
|---|---|---|
| 盲测真实率 ≥ 60% | 需人工判断 | 交付 `check:blind` 材料 + 评分表 |
| 年代一致性 ≥ 70% | 需人工判断 | 同上；`era_check_json` 只做穿帮二值判定 |
| AI 感投诉率 ≤ 5% | 需要真实用户 | 无兜底，上线后监控 |
| 面部相似度 ≥ 0.55 | 需 ArcFace 类模型 | **本期不实现**，列为后续 ticket；`generation_results` 已预留 `realism_score` 列 |
| 生成图的真实美感 | 主观 | 无 |
