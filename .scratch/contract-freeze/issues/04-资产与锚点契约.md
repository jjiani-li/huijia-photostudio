# 04: 资产与锚点契约

**What to build:** 从上传到锚点提取这一段的契约缺口全部关闭。照片格式判定的两类失败各有明确去向、预处理依赖的数据访问签名补齐、评分输入形状不再引用未定义的符号、锚点结构对多余键有唯一处置、prompt 版本有明确的注册与未知版本错误、年龄偏差这条核心约束终于有机器判据。

**Blocked by:** 01 闸门上线

**Status:** ready-for-agent

- [ ] 容器可解析但读不到宽高、与解码器打不开文件，两种情况各有明确去向，且错误码到两种情况的映射写明
- [ ] 允许上传的格式与入库记录的格式取值一致
- [ ] 预处理模块依赖的数据访问签名与软删条件已在权威签名清单里声明
- [ ] 评分所需的输入形状显式声明，伪代码不再引用未定义符号
- [ ] 锚点结构对多余键的处置唯一（丢弃或失败，二选一），测试用例与实现一致
- [ ] prompt 版本注册表显式声明，未知版本映射到明确的错误码
- [ ] 年龄偏差有登记在册的检查项，且该检查项在注册表里可查
