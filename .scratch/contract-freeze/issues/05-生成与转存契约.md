# 05: 生成与转存契约

**What to build:** 生成链路的调度与判据不再互相打架。三张任务表公平轮转、并发排他检查与事务语义正确、审核拒绝与任务终态的关系唯一、结果图尺寸取实测值、"可复现"的说法与真实能力对齐、未验证的上游能力带着标记而不是被当作事实。

**Blocked by:** 01 闸门上线

**Status:** ready-for-agent

- [ ] 三张任务表按轮转拉取，任何一张都不会被更长的队列饿死
- [ ] 排他性检查在插入之前执行，字面实现不会把用户的第一次生成拒掉
- [ ] 事务语义与繁忙错误的处理写明，繁忙错误归入可重试集合
- [ ] 被内容审核拒绝的结果张不写结果行、不计入张数，任务终态由张数决定
- [ ] 结果图与照片记录的宽高取转存后实测值，不写请求参数
- [ ] "可复现"的表述在全部文档中统一为"可重新提交复现"，且不为该能力预留无证据的字段语义
- [ ] 未验证的上游能力集中登记在诚实边界处，并逐条标注"未验证"
