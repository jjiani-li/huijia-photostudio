# 09: 历史与结果页口径

**What to build:** 用户能看到并彻底删除自己上传的任何照片（包括上传了但没走完流程的），能表达"不像本人"，下载得到的文件与真实格式一致，上传多选时的取数不再依赖此时拿不到的值，反向提示词这个旁路能力不再必须先走完全链路。

**Blocked by:** 01 闸门上线

**Status:** ready-for-agent

- [ ] 未走完流程的照片在界面上可见，并能用同一套删除确认彻底删除
- [ ] 对应的读取路径在接口契约里有定义，且不与按锚点分页的历史查询混用同一次分页
- [ ] 反馈取值域含"不像他"，并给出换一张照片的路径；本期该值只落库留痕、不做聚合
- [ ] 下载文件扩展名从生成参数里的输出格式派生
- [ ] 上传多选时的取数规则不依赖此时尚未产生的值
- [ ] 反向提示词的入口落在"照片已存在即可用"的位置，依赖边与归属一致
