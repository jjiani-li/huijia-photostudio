# 02: 契约单点化

**What to build:** 每一类契约从此只有一处定义。错误码只在接口契约里定义，各模块文档只引用；prompt 的长度阈值与正文各只剩一处；worker 的任务来源、claim、心跳与回收只在技术基线里定义。改完之后，任何人再复制一份契约，闸门都会拦下来——治的是"同一件事写了很多遍，于是互相打架"这个病根。

**Blocked by:** 01 闸门上线

**Status:** ready-for-agent

- [ ] 各模块文档里自行复述的错误码表体已删除，全部改为引用接口契约
- [ ] 错误码的唯一事实源之外不再出现错误码表，且闸门有对应断言
- [ ] prompt 长度只有一处阈值声明，其余位置改为引用
- [ ] prompt 正文以代码为唯一事实源，文档只写结构与约束，并有"文档与代码等值"的断言
- [ ] worker 的任务来源、claim 原子性、心跳与回收只有一处定义，模块文档不再复述
- [ ] 任务来源"几张表"在全部文档中只有一个说法
- [ ] 施工纪律里写明"不许复制契约，只许引用"，并规定契约级分歧不得记成工单的待定决策
