## 3. 引用约定（v3 强制）

1. 所有文档间引用**一律写作相对 `docs/prd/` 的完整路径**，例如：
   - `spec/03-接口契约.md` §3.5
   - `modules/M05-年代场景配置与Prompt拼装.md` §5.4
   - `pages/P01-页面规格.md` §4
2. **禁止裸编号引用**。以下写法全部作废，必须展开为完整路径：
   - `` `01` ``、`` `14` ``、`` `09` ``、`` `19` `` → 对应 `spec/…` / `modules/…`
   - `` `03`–`10-后端-*.md` `` → `modules/M01`–`M08`
   - `` `04`–`11` `` → `modules/M01`–`M08`
   - `` `05-后端-...` `` → `modules/M02-预处理与质量评分.md`
3. 同一份文档内部自引也写完整路径，不使用"本文件"以外的省略。
4. **ticket 编号与文档编号是两套编号，不可混用**。`ticket 06` 指 `tickets/T06`；`modules/M03` 指模块文档。
5. 引用 `docs/prd/` 之外的仓库文件时，写**仓库根相对路径**（如 `docs/raw/AIGC_PRD.md`、`.scratch/anchor.json`）。

## 4. 瘦身规则（本次重构的核心动作）

### 4.1 一律保留（不得删减、不得概述化）

- 表字典字段行、列定义、类型、约束、默认值
- `CREATE TABLE` / `CREATE INDEX`、关键 SQL 语句原文
- TypeScript 接口/函数签名、返回类型、枚举值
- 端点：方法、路径、请求/响应字段、状态码
- 错误码表与上游→本项目映射
- 状态机的状态名与迁移条件
- 环境变量表（名、默认值、含义）
- 测试用例 ID、fixtures 清单、"完成判定"条目
- 数字阈值与标定常数（如 `SHARP_FLOOR = 3.0`、`size ≥ 3,686,400`）
- 禁令清单与红线（这些是防止 AI 重新引入被否决行为的唯一屏障）

### 4.2 一律削减

- **论证性长段落**：压到 ≤1 句，保留那句"不做会怎样"的结论即可
- **重复表述**：同一约束在多处出现时，只在权威处保留完整表述，其余处改为一行引用
- **举例**：每类保留最具代表性的一个
- **`docs/raw/AIGC_PRD.md` 原文摘抄**：删除大段引用，只保留结论与出处

### 4.3 一律删除（已失效的过程性内容）

- 各文件 §"与上游文档的差异/本文件与上游的差异"里**关于文档编号争议的条目**（编号已重建，争议消失）
- 「`README.md` §1 表格残留旧编号」这类**描述一个已修复问题**的条目
- 「本文件不改上游」这类协作过程说明

### 4.4 每个文件末尾的"与上游文档的差异"章节处理

章节**编号保留**（交叉引用依赖它），内容替换为 **3–6 行的结论表**，只保留"原始 PRD 怎么写的 → 本方案怎么做 → 一句依据"。删除所有编号争议条目。

### 4.5 章节编号与顺序不得变动

交叉引用依赖 §编号。**保留全部章节标题及其编号与顺序**。若确需删除整节，必须在返回结果里明确报告"删除了第 N 节"，不得静默删除。

### 4.6 行数参考（不是硬指标，细节优先）

| 层 | 现状 | 目标参考 |
|---|---|---|
| `spec/` 各文件 | 最长 ~520 行 | ≤ 260 行 |
| `modules/` 各文件 | 380–450 行 | ≤ 320 行 |
| `pages/` 各文件 | 424 / 500 行 | ≤ 380 行 |

**若削到目标行数会丢失 §4.1 的内容，则保留细节、放弃行数目标。**

## 5. 统一文件头

每份 `spec/`、`modules/`、`pages/` 文档在标题下方插入 3 行元信息块（替换原有的长"章节对应说明"）：

```markdown
> **层级**：规范层 · 全局约束（不可违背）
> **上游**：`docs/raw/AIGC_PRD.md` §2、§5 ／ `spec/00-总纲.md`
> **下游**：`modules/M05`、`tickets/T08`
```

- `spec/` 用「层级：规范层 · …」
- `modules/` 用「层级：实现规格层 · 后端模块」
- `pages/` 用「层级：实现规格层 · 前端页面」
- `上游` 写真正的输入依据，`下游` 写真正会读它的文档/工单。不确定就写"全部下游文档"。

## 6. 交付物不得包含

- 迁移对照表、v2/v3 编号讨论、章节骨架对应说明
- 面向重构过程的自述（"本次重构…"）
- `.scratch/prd-migration-map.md` 本身
